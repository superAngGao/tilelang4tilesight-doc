TileLang 性能分析工具的技术路线与 TileSight 接口说明。

## 六类性能问题

以下按性能分析需求定义问题类型，不表示工具在每个 kernel 上都能作出确定判断。报告应区分模型预测、运行时观测和证据不足。

| 问题类型 | 具体含义 |
|---|---|
| Tile pipeline 瓶颈 | 判断流水时间主要受计算、搬运还是依赖/同步限制，定位决定关键路径或稳态启动间隔（II）的约束。不能只按最长 Phase 判断。 |
| 跨层级搬运异常 | 检查不同存储层级间的流量和搬运代价是否超出同口径预期，或访问效率偏低；流量大本身不等于异常。 |
| 缓存利用异常 | 检查命中率偏低、缓存流量分布及搬运是否异常；保留缓存层级、读写方向、统计分母和判断阈值。 |
| 计算–IO 重叠失败 | 检查计算与搬运是否获得预期重叠，哪些依赖或资源约束限制了重叠。模型时间线与真实执行时间线必须区分。 |
| 负载不均 | 检查执行单元间工作分布、网格与 SM 数量适配及尾波引起的资源闲置；汇总 occupancy 不能证明具体 CTA 的负载分布。 |
| 模型预测偏差 | 标记同一 kernel、输入和测试条件下预测与实测的显著差异，保留结构、工作量、依赖、执行环境和模型假设，供进一步定位。 |

每类问题在两条路径中能提供什么证据、还不能证明什么，见[协议对照索引](技术路线/technical-agreement-report-compliance-cn.md)。

## 版本与范围

- 文档依据的官方 TileSight 版本：`48e4158459bee5df830ae4ab7dda541edaa3dc4d`。
- 适配器实现基线：`b15b4ac`；文档整理于 2026-09-17。
- 当前讨论的主要平台是 NVIDIA H200。
- 文档中的教学时间和缓存示例结果不代表实测精度。
- 本仓库仅发布技术文档，不包含适配器实现、运行时采集程序或实验产物。文中“实现仓库中的路径”用于说明实现位置，不是本仓库文件。

这些文档是对当前接口和实现的说明，不承诺覆盖任意 kernel、任意编译器版本或所有硬件行为。协议对照索引不是最终验收结论。
